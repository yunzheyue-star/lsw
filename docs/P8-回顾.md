# P8 回顾：`lsw <program>` 执行（.exe / .bat / .cmd）

> 验收日期：2026-10-16
> 状态：真机验收通过；`ctest` 115/115，`scripts/verify-p8.sh` 32/32

## 1. 目标与最终行为

在 Windows 环境执行 Linux 侧指定的程序，不支持 GUI：

- `lsw test.exe arg1 arg2`
- `lsw test.bat arg1 arg2`
- `lsw test.cmd arg1 arg2`

最终调用链：

```text
Linux CLI（读取 cwd / argv）
  → IPC `exec { argv, cwd }`
  → lswd：
      1. resolve_target：绝对化、$HOME 判定、PE GUI 检测
      2. $HOME 外复制到 ~/.lsw/tmp/<hash>/（7 天清理）
      3. 生成 PowerShell EncodedCommand：
         - net use Z: \\10.0.2.2\qemu
         - Copy-Item 到 Windows %TEMP%\lsw-exec-<guid>\
         - Unblock-File
         - & $program @argv; exit $LASTEXITCODE
      4. 非交互 ssh 执行，捕获 stdout / stderr / exit_code
  → CLI 透传输出与退出码
```

## 2. 真机验收记录

- 2026-10-16：`lsw test.bat` 输出 `LSW_BAT_OK` / `LSW_BAT_ERR`，退出码 0。
- 交互式 `lsw` 进入 PowerShell 后，`.\test.bat` 可正常返回。
- 终端体验：启动清屏、`RawUI.BufferSize` 归一化、`clear`/`cls` 清理滚动回退均通过。

## 3. 踩坑与修复

### 3.1 从 SMB 映射盘直接执行 `.bat` 卡住

现象：

- `lsw test.bat` 的 SSH 进程长期挂起；
- 在交互 PowerShell 里 `.\test.bat` 同样卡住；
- 批处理内容只有 `echo` + `exit /b`，文件可正常读取。

定位：

- 读取/复制文件正常，只有 cmd.exe 从 `Z:`（SMB 映射盘）执行时挂起；
- 怀疑 SMB oplock/lease 与 Windows 命令处理器文件打开模式互相等待。

修复（双保险）：

1. P8 远端脚本先把程序复制到 Windows 本地 `%TEMP%\lsw-exec-<guid>\`，`Unblock-File` 后执行本地副本；
2. `scripts/lsw-mount-helper` 生成的 host smb.conf 关闭：`oplocks`、`level2 oplocks`、`kernel oplocks`。

### 3.2 PowerShell 交互输入被顶出可视区

现象：ConPTY 下每按一个键，输入行被顶到屏幕外，需要上翻才能看到。

原因：Windows PowerShell 的 `RawUI.BufferSize` 远大于窗口尺寸，PSReadLine 每次重绘触发滚动。

修复：远端 shell 初始化脚本把 `BufferSize` 收敛到 `WindowSize`。

### 3.3 `clear` 只清 Windows 缓冲区，Linux 滚动回退仍残留

修复：

- `lsw shell` 在 `execvp ssh` 前向本地 TTY 发送 `ESC[2J/3J/H`，清掉启动命令行与旧 scrollback；
- 远端 shell 覆盖 `Clear-Host`，`clear`/`cls` 同时清可视区与滚动回退。

### 3.4 OpenSSH post-quantum 警告

OpenSSH 10 连接旧 KEX 服务端时会向 stderr 打印 `post-quantum` 提示；P8 exec SSH 参数增加 `-o LogLevel=ERROR` 静音。

## 4. 退出码约定

| 退出码 | 含义 |
| --- | --- |
| `0` | 程序成功 |
| `5` | 路径映射失败（文件不存在 / 不在 `$HOME` 且复制失败） |
| `6` | VM 未运行、SSH 失败或执行超时 |
| `7` | GUI 程序（`PROGRAM_FAILED`）或未归类执行错误 |
| 其它 `1–255` | Windows 程序退出码原样透传 |
